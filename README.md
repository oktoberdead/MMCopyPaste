# MicroMacro

Расширение браузера для сотрудников чатовой техподдержки: **макросы-шаблоны**.
Назначаете кодовое слово (например, `прив`) и в чате набираете `--прив` — расширение
мгновенно подставляет вместо него заготовленный текст. По умолчанию Enter **не**
нажимается (текст встаёт в поле, отправляете вы сами), но у каждого макроса можно
включить автоотправку: Enter, Shift+Enter или Ctrl+Enter.

Два режима: **макросы** (кодовые слова с автовставкой) и **пасты** (крупные куски
текста с поиском и вставкой через буфер обмена).

Работает в Chrome, Edge, Opera, Яндекс.Браузере (Manifest V3) и Firefox.

## Возможности

- **Вкл/выкл** всей подстановки одним переключателем в попапе.
- **Профили по доменам**: у каждого сайта свой список макросов + общий профиль
  «Все сайты». На странице `ai.sknt.ru` расширение само предложит создать профиль
  для этого домена.
- **Добавление / редактирование / удаление** макросов; кнопка «+ Макрос» закреплена
  над списком и не уезжает при прокрутке.
- Каждый макрос можно **выключить** точечно, не удаляя.
- **Плейсхолдеры локальны для профиля**: `{имя}`, `{отдел}` и т.п. значения задаются
  отдельно в каждом профиле (домен перекрывает «Все сайты»). Встроенные `{дата}`,
  `{время}`, `{datetime}` работают без настройки. Если у `{…}` нет значения, он
  остаётся как есть, а редактор подсвечивает такие плейсхолдеры красным.
- **Ручной триггер Ctrl+Shift+M**: если сайт глушит автовставку, наберите кодовое
  слово (например `--прив`) и нажмите Ctrl+Shift+M — макрос раскроется в текущем
  поле. Работает в любом редакторе, независимо от input-обработчиков сайта.
- **Импорт базы из .md / .txt** (в настройках): файл с записями вида
  `--ключ: текст` разбивается на макросы и кладётся в выбранный профиль либо в
  новый (укажите домен). Многострочный текст поддерживается, существующие ключи
  перезаписываются.
- **Telegram:** автозамена `--` на длинное тире учтена — триггер срабатывает и на
  `—прив`, и на `–прив`.
- **Автоотправка как опция макроса**: после подстановки можно эмулировать
  Enter / Shift+Enter / Ctrl+Enter (по умолчанию выключена).
- **Вкл/выкл профиля**: кнопка «Профиль: вкл/выкл» или ПКМ по пилюле профиля;
  состояние видно по цвету пилюли (зелёная/красная).
- Поля: обычные `<input>`/`<textarea>` и `contenteditable`-чаты (Telegram, Google,
  Arena) — текст собирается по всем текстовым узлам, работает даже при разбитом DOM.
- Умный триггер: `--прив` не сработает внутри слова (`abc--прив`), а при ключах
  `прив`/`привет` короткий подождёт, пока вы допишете или поставите пробел.
- Настройка **префикса** (по умолчанию `--`).
- **Экспорт/импорт** всех макросов в JSON — удобно делиться базой с коллегами.
- Ничего никуда не отправляется: все данные лежат локально в `chrome.storage.local`.

## Пасты и поиск

- В попапе по умолчанию открыт режим **«Пасты»**; под шапкой тумблер
  **«Пасты | Макросы»**. В режиме паст нет профилей и триггеров — только список и поиск.
- **Поиск**: нормализация (нижний регистр, `ё→е`) + подстрока; несколько слов — все
  должны встречаться; заголовок весит больше тела; совпадение показывается сниппетом.
- **Клик по пасте** (или ⧉) копирует её в буфер обмена с подстановкой плейсхолдеров
  (`{имя}`, `{дата}`/`{время}`, vars «Все сайты») — вставляете Ctrl+V куда угодно.
- **Массовое удаление паст**: кнопка «Удалить все пасты» в настройках (с подтверждением).
- Добавление/правка/удаление паст — в попапе и в настройках.
- **Импорт .md/.txt с `## Заголовок`** (в настройках, секция «Пасты»): каждый блок
  `## …` становится пастой; старый формат `--ключ: текст` по-прежнему идёт в макросы.
- На странице настроек списки макросов и паст спрятаны за дропдауны
  «Список макросов ˅» и «Пасты ˅».

## Установка (Chromium: Chrome / Edge / Opera / Яндекс)

1. Соберите дистрибутив: `npm install && npm run build` → папка `dist/chrome`
   (или возьмите готовый `dist/mmcopypaste-chrome.zip` и распакуйте его).
2. Откройте `chrome://extensions` (в Edge — `edge://extensions`, и т.д.).
3. Включите **«Режим разработчика»** (справа сверху).
4. Нажмите **«Загрузить распакованное расширение»** и выберите папку `dist/chrome`.

Можно грузить и прямо из корня репозитория — там лежит базовый `manifest.json`.

## Установка (Firefox)

1. `npm run build` → папка `dist/firefox` (или `dist/mmcopypaste-firefox.zip`).
2. Откройте `about:debugging#/runtime/this-firefox`.
3. Нажмите **«Временная установка дополнения…»** и выберите
   `dist/firefox/manifest.json`.

> Firefox разрешает постоянную установку только подписанных дополнений; для личного
> использования достаточно временной установки (или отключите проверку подписи в
> Developer Edition).

## Как пользоваться

1. Кликните по иконке расширения.
2. Переключатель справа сверху включает/выключает подстановку.
3. Чипы сверху — профили: «Все сайты» и ваши домены (зелёный = включён,
   красный = выключен). ПКМ по чипу — вкл/выкл профиль. `+ ai.sknt.ru` создаёт
   профиль для текущего сайта.
4. «+ Макрос» (закреплена над списком) → кодовое слово, текст и режим отправки →
   «Сохранить».
5. В чате наберите `--прив` — текст подставится (плейсхолдеры `{имя}` возьмутся из
   vars активного профиля).

На странице настроек (иконка → «Настройки и полный список»): префикс, добавление и
удаление доменов, плейсхолдеры профиля, экспорт/импорт. В попапе управления
профилями нет — только вкл/выкл через ПКМ.

## Разработка

```bash
npm install        # зависимости (только для тестов: jsdom)
npm test           # node --test: ядро, домены, хранилище, content script и UI (jsdom)
npm run build      # dist/chrome + dist/firefox + zip, с проверкой манифестов
npm run icons      # пересоздать иконки (нужен ImageMagick)
```

Исходники — классические скрипты без бандлера, поэтому расширение ставится как есть,
а в тестах исполняется ровно тот код, который уезжает в браузер (ядро — через `vm`,
content script и UI — через `jsdom`).

```
manifest.json           базовый манифест MV3 (Chromium)
src/core/               чистая логика: триггер, домены/профили, хранилище
src/content/content.js  content script: слушает ввод и подставляет текст
src/ui/                 попап и страница настроек (общий компонент)
icons/                  иконки (генерируются tools/make-icons.sh)
tests/                  unit- и интеграционные тесты (node:test + jsdom)
tools/build.mjs         сборка dist/chrome и dist/firefox + zip
```
